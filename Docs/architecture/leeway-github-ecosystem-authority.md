# LeeWay GitHub Ecosystem Authority

This registry converts the recovered LeeWay estate into a GitHub-first control plane without erasing the architecture learned from the earlier workstation and Docker deployments.

## Law

GitHub owns source/control identity. LeeWay Standards owns governance. Formula Live owns canonical mathematical authority. Agent Skills owns capability/orchestration authority. Runtime Fabric owns persistent execution. Device Bridge owns native/physical device execution. Federate Web projects discovery and transport. LeeWay OS is the primary operating-system experience.

Docker, local ports, drive letters, browsers, model providers and devices are adapters or deployment bindings. They are never ecosystem identity.

## Recovery boundary

`4citeB4U/LEEWAY-D-DRIVE-RECOVERY-20260925` remains forensic evidence. Recovered artifacts are promoted selectively through compare -> qualify -> test -> Veritas -> receipt. Recovery branches are never wholesale canonical replacements.

## Public/static boundary

GitHub Pages may publish UI, manifests, packages, discovery data and evidence. Persistent jobs, filesystem/process authority, secrets and physical-device actuation require an authorized runtime or native bridge.

## Formula boundary

The registry references `LEEWAY-FORMULA-v1.0`; it does not execute Formula or invent Q69 state. Consumers must use the centralized Formula evaluator contract when authorized.

## Application contract

Applications implement `contracts/leeway-application-manifest.v1.schema.json` so LeeWay OS and Federate Web can discover capabilities/dependencies without hard-coding ports or copying authority.
