# Runtime Domain Governance — Knowledge

## Purpose

The `knowledge` domain governs retrieval surfaces, standards references, registries, and documentation-backed context used by runtime agents.

## Canonical Rule

> Knowledge retrieval must remain attributable, source-aware, and subordinate to LeeWay Standards constitutional law.

## Responsibilities

- maintain discoverable standards references
- prevent drift between prose docs and machine-readable registries
- preserve source attribution for retrieved runtime context
- ensure loaders consume canonical registries

## Allowed State

- standards docs
- registry snapshots
- retrieval indexes
- knowledge ledgers and mappings

## Forbidden State

- unverifiable source claims
- private shadow registries treated as canonical
- undocumented runtime identity overrides

## Minimum Law

- reference canonical standards files
- record source path for promoted knowledge
- keep retrieval claims auditable
