# 🎓 Sovereign Architect Master Class

Welcome to the **LeeWay Standards & Agent Lee Master Class**. This curriculum is designed to transform traditional developers into elite **Sovereign System Architects**.

## 🎯 Purpose and Design

The software development landscape is rapidly shifting toward AI-native codebases. However, traditional AI agents suffer from the "Black Box" problem—they generate code without auditability, lack persistent memory, and often break their host systems because they are not governed by strict architectural rules.

**The Purpose of this Master Class** is to teach you how to build, deploy, and govern a multi-agent AI ecosystem that is **Discoverable, Auditable, Repairable, and Safe to Evolve**. You will learn how to transition from writing manual scripts to orchestrating the **7 Sovereign Agent Families** through a mandatory **8-Stage Execution Spine**.

## 🏛️ The Foundations of Sovereignty

### 1. The Governance-First Philosophy
Every Agent Lee system operates on four unbreakable pillars:
*   **Discoverable:** No hidden AI logic. Every workflow is mapped.
*   **Auditable:** The **Veritas Gate** strict-scores all outputs (85/100 minimum) before execution.
*   **Repairable:** Automatic injection of tracking headers via the `AutonomyAuditor`.
*   **Safe to Evolve:** Continuous learning via the Triple-Threat Memory System (Episodic, Semantic, Procedural).

![Governance Runtime](../public/governance_runtime_1775788428305.png)

### 2. The Society of Agents (The 7 Families)
You will not manage a single massive LLM. You will orchestrate a fleet of specialized AI families:
*   **Nexus:** Interface & Communication
*   **Nova:** Coding & Refactoring
*   **Atlas:** Knowledge & Memory
*   **Shield:** Security & Compliance Enforcement
*   **Aura:** Media & Presentation
*   **Chronos:** Automated Chron-Jobs & Pipelines
*   **Prime:** The Final Speaker (Agent Lee)

![Agent Fleet](../public/agent_fleet_1775788317178.png)

### 3. The Sovereign Cycle
You will learn to construct the heartbeat of the ecosystem: The 8-Stage Cycle. Every user request must traverse:
`Perception -> Origin -> Structure -> Execution -> Veritas -> Echo -> Synthesis -> Lee Prime`

![Workflow Consensus](../public/workflow_consensus_1775788336583.png)

### 4. The Complete Fleet (100+ Agents)
The repository houses a highly structured, 5-tier architecture containing over 100 specialized micro-agents:
*   **Layer 1: The Core Families (`legacy/`)**: The original 7 Families (`Nexus`, `Nova`, `Shield`, `Atlas`, `Aura`, `Chronos`, `Prime`).
*   **Layer 2: Orchestration & RTC (`rtc/`)**: High-speed synchronous agents managing memory and UI routing (`azr-coordinator.js`, `bus.ts`, `governor.ts`).
*   **Layer 3: The Governance SDK (`governance/`, `standards/`, `security/`)**: The CLI enforcement fleet (`audit-agent`, `secret-scan-agent`, `align-agent`).
*   **Layer 4: Autonomous Microservices (`service/`)**: Background daemons for quarantine, dead code reaping, and import monitoring.
*   **Layer 5: Machine Control Protocols (`mcp/`)**: Agents designed to safely interface with the host OS (`process-agent`, `env-agent`, `transport-agent`).
