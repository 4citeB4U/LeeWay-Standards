# Module 4: The Execution Spine & Runtime Governance

To prevent ecosystem chaos, the LeeWay Standard organizes the entire AI architecture into a hierarchical "Execution Spine." This structure ensures that specialized agents, MCPs, and visual workers report correctly through governed runtime lanes up to Lee Prime.

## The Execution Spine Blueprint
The Execution Spine is a vertical structure where data transforms across the 8 stages of the Sovereign Cycle (from Perception down to Synthesis). As requests move down the spine, they are handled by declared runtime lanes and validated execution units.

## The Canonical Runtime Lanes
The sovereign ecosystem is divided into governed runtime lanes. Specialized agents and MCPs belong to a lane and report through explicit governance surfaces.

1. **Sovereign Coordination**
   *   *Role*: `agent-lee-prime` remains the final speaker, routes governed work, and preserves constitutional output.
2. **Engineering and Host Action**
   *   *Role*: `fs-nav-agent`, `mutation-agent`, `host-exec-agent`, and engineering MCPs perform controlled workspace action.
3. **Memory and Knowledge**
   *   *Role*: `memory-warden-agent`, `leeway-memory`, `memory-mcp`, and retrieval systems preserve evidence-bearing continuity.
4. **Security and Trust**
   *   *Role*: `shield-governor-agent`, `attestation-marshal-agent`, `threat-sentinel-agent`, and `leeway-validation` enforce approvals, receipts, and safe operation.
5. **Perception and Media**
   *   *Role*: `perception-agent`, `media-forge-agent`, browser tooling, and media-capable models interpret the outside world.
6. **Planning and Optimization**
   *   *Role*: planners, build auditors, responsive UI auditors, and repo-wide validators govern structured change loops.
7. **Visual Intelligence**
   *   *Role*: LVIS routes image, vector, voxel, scene, repair, export, and project-integration work under a dedicated governed subsystem.

## The Veritas Gate Pipeline
A crucial part of the Execution Spine is the **Veritas Gate**. Before any code is written to disk or any output is shown to the user, the execution thread must pass through this audit-first pipeline governed by the security and trust lane. If compliance is not met, the task is routed back through governed repair loops.
